### 4. Advanced Drive & Safety Technology

- **Permanent Magnet Synchronous (PMS) Gearless Machine**: Up to 40% energy savings, gearless whisper-quiet operation (<50 dB), and low thermal emission.
- **Closed-Loop V3F Vector Control**: Smooth S-curve acceleration and deceleration with ±3mm floor leveling precision.
- **Automatic Rescue Device (ARD)**: Instant emergency battery backup that brings the car safely to the nearest landing and opens doors during utility blackouts.
- **Multi-Beam Infrared Light Curtain**: 128-beam optical sensor web preventing door closure when passengers or objects enter the threshold.

## 💻 Tech Stack & Architecture

- **Core Framework**: [React 18](https://react.dev/)
- **Build System**: [Vite 5](https://vitejs.dev/) with hot module replacement (HMR)
- **Routing**: [React Router DOM v6](https://reactrouter.com/) configured with base path support
- **Styling**: [TailwindCSS v3](https://tailwindcss.com/) with extended color palettes (`brand-teal`, `brand-gold`, `slate`), custom shadows, and animations
- **Iconography**: [Lucide React](https://lucide.dev/)
- **Brochure Engine**: Interactive multi-page PDF/spread viewer with zoom and page jump controls
- **Responsive Navigation**: Unified `PageHero` with breadcrumb navigation and outside-click mobile drawer

## 🚀 Getting Started Locally

### Prerequisites
- [Node.js](https://nodejs.org/) (version 18.0.0 or higher recommended)
- [npm](https://www.npmjs.com/) (version 9.0.0 or higher)

### Setup Instructions

```bash
# 1. Clone the repository
git clone https://github.com/Vyom1912/KrupaElevator.git

# 2. Enter project root
cd KrupaElevator

# 3. Install npm dependencies
npm install

# 4. Start local development server with HMR
npm run dev
```

Open `http://localhost:5173/KrupaElevator/` in your browser to view the application.

### Build for Production

```bash
# Generate optimized static bundle in /dist
npm run build

# Preview the production build locally
npm run preview
```

## 🚀 Deployment (GitHub Pages)

The repository is configured for automated continuous deployment using **GitHub Actions**:

1. **Repository Settings**:
   - Navigate to `https://github.com/Vyom1912/KrupaElevator/settings/pages`.
   - Under **Build and deployment > Source**, ensure **`GitHub Actions`** is selected.
2. **Automated Pipeline**:
   - Any commit pushed to the `main` branch automatically triggers `.github/workflows/deploy.yml`.
   - The workflow runs `npm ci`, compiles the production bundle with base path `/KrupaElevator/`, and deploys the build artifact to GitHub Pages.
3. **SPA Routing Support**:
   - A `public/404.html` fallback script captures client-side sub-routes upon hard refresh or direct URL entry, redirecting cleanly to the React Router context without 404 errors.
